Pattern settings

100% preserves the base layout. Spacing adjusts motif centers and tile dimensions together, without resizing motifs. Smaller values can cause overlaps.

Positions locate each motif’s center in native units before spacing is applied. Motifs wrap at tile boundaries. Select a motif, then adjust its position and inversion.

Fullscreen animation

Random starting positions gives each trail a seeded starting point. When disabled, all trails start at position zero on their motifs.

Trail length is a percentage of the motif perimeter, including the fading ends. Changing it enables animation; reduced motion still shows complete outlines.

Each motif uses its own fixed drawing delay, before the first drawing and after its tail finishes. Disable pauses for continuous movement. Repeated tile copies share their motif’s timing.

Placement is a percentage of one tile. Positive values move right/down. Whole-tile shifts repeat the same placement. Adjusting placement switches to screen preview; tile layout stays anchored.

config.js

Comments and untouched settings are preserved. Replace the contents of config.js with this complete module, then run npm run build. Preview mode, animation/effects toggles, and the preview seed are not exported; saved appearance and seed settings are preserved.
